# 招聘推荐系统设计与实现
> 《行业大数据领域分析综合实践》课程大作业｜大数据全栈综合项目

## 📖项目简介
模拟线上招聘平台，完成招聘岗位数据爬虫采集、基于Hadoop‑Spark‑Hive构建四层离线数据仓库；结合KNN协同过滤实现岗位个性化推荐、随机森林回归完成薪资预测；基于SpringBoot+Vue搭建求职者前台与管理后台完整业务系统。

## 🛠技术栈
- 大数据：Hadoop3.x(伪分布式)、Spark3.x、Hive3.x、Sqoop
- 数据采集：Python、DrissionPage、APScheduler定时爬虫
- 数仓设计：Hive外部表，ODS/DIM/DWD/DWS四层分层数仓
- 机器学习：K‑NN协同过滤（岗位推荐）、随机森林回归（薪资预测）
- 后端：Java8，SpringBoot，Ruo‑Yi若依框架
- 前端：Vue2，分为求职者PC门户、Admin后台管理系统
- 存储：MySQL8.0、Redis

## ✨核心功能
1. **数据采集模块**：定时爬虫抓取招聘岗位数据，输出CSV，写入HDFS、MySQL业务库
2. **Hive四层数据仓库**
- ODS贴源层：原样接入爬虫、业务库原始数据，保障数据可回溯
- DWD明细层：完成脏数据过滤、清洗，生成岗位明细宽表
- DIM维度层：行业、学历、经验等维度字典表
- DWS汇总层：面向业务聚合行业薪资、投递热度等统计指标，供可视化与模型调用
3. **求职者前台业务**：注册登录、简历编辑、岗位检索、岗位收藏、简历投递、个人中心
4. **算法智能模块**：KNN协同过滤实现岗位个性化推荐；随机森林回归实现岗位薪资预测
5. **Admin管理后台**：用户管理、企业/岗位维护、爬虫原始数据管理、权限管控
6. **系统监控可视化**：对Redis缓存运行指标做可视化监控，观测内存、命令调用占比

## ▶运行说明
1. 部署CentOS7伪分布式Hadoop+Spark+Hive大数据环境
2. 执行爬虫脚本，采集招聘岗位数据上传HDFS，同步MySQL业务库
3. 执行Hive SQL脚本，构建四层离线数仓，完成分层ETL
4. 启动SpringBoot后端，分别启动Vue前台、管理后台
5. 运行机器学习模型，将推荐、薪资预测能力对接前端页面
